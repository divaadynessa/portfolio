# Diva Diamantiara Dynessa — Portfolio Website

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. Visual direction: iOS-inspired soft pink/blue with translucent glass surfaces.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and project filters
- `assets/` — add verified project images and screenshots here

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a local development server, use VS Code Live Server or run `python -m http.server 8000` in this folder, then open `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose the publishing source and deploy from the main branch.
5. GitHub Pages will provide the public website URL after deployment.

Official guide: https://docs.github.com/en/pages/quickstart
